# Available Agent Skills Catalog

> [!TIP]
> This rule is accessible anytime by typing `@skills-menu` in the chat input. It provides a complete index of all specialized skills ready to use in this project.

## 🛠️ Debugging & Refactoring
- **`systematic-debugger`**: Systematic root-cause investigation (Garry Tan / Sentry). Traces data flow, tests hypotheses, and eliminates guesswork bug fixes.
- **`code-refactor`**: Clean code & DRY refactoring (Matt Pocock / Clean Architecture DDD). Component decoupling, TypeScript strict typing, single responsibility.

## 📐 Planning & Architecture
- **`spec-driven-planning`**: Spec-driven development (NeoLabHQ SDD). Clarifies requirements, defines data contracts, edge-case analysis, and milestone roadmaps.

## ⚡ Tech Stack Specialists
- **`nextjs-app-router`**: Next.js 16 & React 19 App Router (Vercel Labs). Server vs Client component boundaries, route groups, server actions, and caching.
- **`tailwind-v4-styling`**: Tailwind CSS v4 CSS-first design tokens (`@theme`), responsive mobile-first layouts, and accessible color contrast.

## 🎨 UI/UX & Web Quality
- **`frontend-ux-design`**: Anthropic frontend design principles. Reference layout fidelity, micro-interactions, responsive geometry, and form ergonomics.
- **`web-quality-audit`**: Addy Osmani Web Quality. Core Web Vitals (LCP, INP, CLS), WCAG AA accessibility, SEO metadata, and bundle optimization.

## 🗄️ Backend & Databases
- **`database-firebase`**: Firebase Firestore NoSQL schema, real-time listeners, security rules (RBAC), and Spark free-tier quota efficiency.
- **`database-supabase`**: Supabase PostgreSQL relational schema, Row-Level Security (RLS) policies, and server-side Auth.

## 🧪 Testing & Deployment
- **`webapp-testing-playwright`**: Playwright browser automation (Anthropic / TestMu AI). Headless E2E tests, resilient role locators, and viewport matrix checks.
- **`production-deploy`**: Netlify & Vercel deployment workflows. Pre-deploy quality gates, secrets management, and zero-downtime rollbacks.
